How to use

Drag a `.gcode` file onto the viewer or press Open GCODE. Use the layer slider at the bottom. Mouse wheel zooms, left-drag pans. Enable Colour extrusion by Linear Advance K to show M900 K… values as a smooth colour ramp. This is designed for height-varying K scripts that insert a new K value on each layer. Choose a palette above, and use All layers or 3D-ish preview to see the gradient through the print. Playback can also simulate Marlin-style acceleration and Classic Jerk timing. In 3D-ish preview, the printer origin (0,0,0) is oriented at the front/lower-left, with +X to the right and +Y towards the rear. Enable Realistic extrusion line thickness to draw extrusion moves at an estimated physical width based on extrusion amount, move length, layer height and 1.75 mm filament unless M200 D… specifies another diameter.
